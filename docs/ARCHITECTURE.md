# 架构与实现要点

## 0. 分层

- `src/Core`：后端（数据、存储、启动、应用发现、图标）。唯一入口是 `DeskService`，契约见 [BACKEND_API.md](BACKEND_API.md)。构建时会单独编译以确保它不依赖 UI。
- `src/UI`：前端（下面各节描述的窗口、材质、动画）。只通过 `AppController.Service`（`DeskService`）读写数据，订阅它的 `Changed` 刷新。
- `src/Host`：`Program.cs`（入口、`--self-test`、`--bench`、桌面层级维护）与 `NativeDesktopHost.cs`（挂到 Explorer 桌面视图）。

## 1. 窗口拓扑

- `HomeForm`：左侧时钟 / 日历小组件，**不**作为独立顶层窗口，而是挂在桌面 `SHELLDLL_DefView` 下的 `WS_CHILD`，并保持在 `SysListView32` 之前。
- `DesktopFolderForm`：桌面文件夹画布，同样是 `SHELLDLL_DefView` 的子窗口。它还负责在文件夹打开期间接管键盘焦点（见第 4 节）。
- `BackdropOverlay`（`src/UI/Folder`）：覆盖工作区，呈现模糊压暗的背景。截图就绪后只更新整体透明度。`WS_EX_NOACTIVATE`，点击会关闭文件夹。
- `FolderLayer`（`src/UI/Folder`）由所有文件夹复用。开合时窗口跟随当前帧的绘制范围，绘图缓冲按面板尺寸预留。从展开第一帧到收起最后一帧，它负责绘制和处理输入。窗口使用 `WS_EX_NOACTIVATE`，owner 为程序内部隐藏窗口。

不写 Shell 的 Z 序、不设置全局 topmost、不安装任何全局钩子。

MacDesk 窗口成功挂载后，临时隐藏原生桌面图标列表 `SysListView32`。托盘退出时恢复 MacDesk 隐藏的列表，改动仅作用于本次会话的窗口可见状态。桌面文件夹的布局按时钟和日历的当前位置计算可用列，两侧都放不下完整一列时使用上方或下方的空间。

## 2. 毛玻璃

不再使用 Win11 Acrylic（它无法动画，也给不了大圆角抗锯齿）。所有材质都由程序自己画，保证过渡帧与静止面板用的是同一种材质：

- **桌面材质**（`Wallpaper`）：按注册表里的壁纸路径与 `WallpaperStyle`（填充 / 适应 / 拉伸 / 居中 / 平铺）在主显示器上重建壁纸，降采样后进行三次盒式模糊并提高饱和度。文件夹图标与小组件按自身屏幕位置放大采样区域，再叠上一层色调。原图丢失时回退到 `TranscodedWallpaper`。
- **展开背景**（`Backdrop.CaptureScreen` / `FromCapture`）：鼠标按下时抓取展开前的画面。线程池生成低分辨率模糊，将压暗背景直接写入最终提交的 DIB 像素缓冲。点击松开即可启动文件夹动画，背景就绪后由界面线程接管缓冲并淡入。面板玻璃保留低分辨率模糊源，只放大实际采样的区域。
- **展开面板**（`FolderGlass`）：模糊取样和色调只在背景变化时合成一次。动画每帧逐行复制圆角内部的像素，边缘查贝塞尔曲线表计算抗锯齿覆盖率。静止面板用同一套取样生成缓存。
- 圆角统一用连续曲率的 `Ui.Squircle`（三次贝塞尔近似），所有 layered 窗口都是 32bpp 预乘 alpha，边缘自带抗锯齿。

## 3. 动画

原则：**一个时钟、一个状态、一套几何、一个渲染器**。

1. **一个时钟**（`src/UI/Motion/AnimationClock.cs`）：后台线程用 `DwmFlush()` 等每次合成（本机 240Hz），向 UI 线程投递一帧；所有正在动的东西（桌面文件夹、小组件、文件夹层）在同一帧里用同一个 dt 推进。每个视图持有一个 `FramePump`，它只是对时钟的订阅，全部静止后时钟自动停止。所有 GDI+ 绘制都在 UI 线程上。（不用 WM_TIMER：Win11 会把它合并到约 15.6ms。）
2. 文件夹的开合由进度弹簧 `p` 驱动（`FolderLayer.progress`，临界阻尼，response 为 0.27 秒）。打开目标设为 1，关闭设为 0。中途反向时弹簧保留速度，背景压暗程度随 `p` 同步变化。
3. **一套几何**（`src/UI/Folder/Metrics.cs`）：`Metrics` 集中所有尺寸常量（桌面图标 80px、格子、面板内图标 64px、圆角、3×3 缩略图的小格 `MiniSlot`）；`FolderLayout` 是纯函数、输出整数像素（面板大小与位置、格子列数与左边距、格子里的图标矩形）。桌面画布、面板绘制、点击判定、拖动换位、展开动画都只用它。
4. `FolderLayer.Render()` 根据进度选择绘制内容。`p < 1` 时画 `Geometry(p)` 生成的过渡帧，`p = 1` 时画打开后的面板。
5. `FolderLayer.Geometry(p)` 计算共享元素过渡。外框从桌面文件夹图标扩展成面板，缩略图里的图标各自移动到对应的格子。其余图标、名称和“添加”在后段淡入。标题随外框移动并淡入。收起沿同一条路径反向播放。
6. **像素规则**：所有终点都是 `FolderLayout` 给出的整数像素，过程中用小数；`p → 1` 时连续逼近终点，没有"切换到清晰模式"的那一帧。
7. **其余动效**（悬停、按下、回流、滚动、搜索栏、月份滑动）：每个属性一个 `Spring`（SwiftUI 式参数），固定步长积分，60Hz 与 240Hz 下结果一致。
8. `LayeredSurface` 复用 DIB。桌面文件夹画布按脏矩形提交像素，文件夹面板提交当前窗口范围。图标（64 px）和文字标签各缓存最近使用的 384 张位图，滚动时只绘制视口内的格子。过渡动画淡入标签时，仅在文字和阴影占用的矩形内进行透明度混合。面板复用已生成的磨砂底。
9. 日历移动时，桌面只重绘换位或遮挡发生变化的玻璃框，以及与脏区重叠的内容。玻璃框沿用原纹理完成位移动画，到达新格位后再采样壁纸。
10. `IconLoader` 在后台分批提取视口内的图标，每批最多四张，优先处理展开面板的请求。界面线程在开合动画结束后更新缓存，并刷新用到该批图标的缩略图。
11. 添加应用时，搜索在内存里匹配应用名称和快捷方式路径。`AppCatalog` 在后台读取上次保存的目录，并从桌面、开始菜单及快捷入口目录更新候选。再次打开添加面板时，后台按需刷新，界面沿用当前目录直到结果就绪。

**不变量**（`--self-test` 离屏扫一遍 `p` 检查，见 `FolderLayer.CheckTransitionInvariants`）：任何时刻每个图标都在外框内（"图标先到、框后到"在结构上不可能）；每个图标随 `p` 单调靠近终点；`p = 1` 时每个图标恰好等于 `FolderLayout` 的整数位置；打开到一半反向时相邻帧不跳变。

## 4. 焦点与键盘

文件夹 UI 的所有窗口都**不激活**。原因：在 Win+D（显示桌面）状态下，任何其他窗口获得激活都会让 Windows 退出该状态并把所有窗口还原到最前，文件夹随即被盖住。

键盘输入改由 `DesktopFolderForm` 接收：它是桌面视图的子窗口，与 Explorer 桌面线程共享输入队列，可以在桌面保持激活的同时拿到焦点。打开文件夹时 `TakeKeyboardFocus`，关闭时把焦点还给原来的桌面控件。按键经 `AppController.RouteKey / RouteChar` 转给面板；重命名在面板内自绘输入框，并用 `ImmSetCompositionWindow / ImmSetCandidateWindow` 把输入法窗口放到输入位置。

若其他程序成为前台（`GetForegroundWindow` 不是桌面也不是本进程），面板自动收起，不会留下一层压暗背景。

从面板启动应用时，后台线程把原快捷方式交给本会话的 Windows Shell。Shell 接受启动请求后直接收起面板。普通关闭继续播放收起动画。

## 5. 拖放

- 纯文本拖放格式 `MacDeskNative.Item` = `sourceGroupId + "\n" + itemId`。
- 外部文件走标准 `FileDrop`，通过 `EntryServices.FromPath` 生成入口（只记录路径，绝不移动原文件）。
- 面板内排序时，可视槽位先映射回真实下标再保存（搜索过滤状态下槽位 ≠ 下标）。

## 6. 存储

`DesktopStore`：

- 读入后克隆一份数据供 UI 使用；
- `Edit` 在克隆上修改、校验、序列化，再用 SHA256 比对磁盘内容，最后原子替换并写带哈希的备份到 `Backups`；
- 任何一步失败都回滚内存数据，不会出现「界面显示成功但磁盘没写」。

## 7. 时区

时钟固定北京 UTC+8：读取 UTC 时间后 `AddHours(8)`，不依赖系统时区，也不修改系统设置。`BeijingFromUtc` 会拒绝非 UTC 的输入，避免重复偏移。

## 8. 诊断

设置环境变量 `MACDESK_FRAME_LOG=<文件路径>` 启动后，会记录真实桌面上每帧的耗时与间隔。

`MacDesk.exe --bench <输出文件>` 离屏测量桌面文件夹悬停与换位、时钟和日历拖动、日期悬停与翻月、文件夹开合、面板悬停与换位、键入搜索及添加页滚动的耗时。设置 `MACDESK_BENCH_FRAMES=<目录>` 可以导出关键帧 PNG。240 Hz 下每帧预算约 4.2 ms。
